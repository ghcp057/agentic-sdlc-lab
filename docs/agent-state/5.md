# Issue 5: Order returns

Orders may transition from `DELIVERED` to `RETURNED`. `RETURNED` is a terminal
status and cannot be cancelled.

## Open questions

- Should `DELIVERED` be terminal, as required by issue #6, or should it allow a
  transition to `RETURNED`, as required by issue #5?
- Should returns be allowed only within 30 days of delivery?

Orders do not currently track a delivery date, so the 30-day window cannot be
enforced unless delivery-date tracking is designed separately. No delivery date
or cutoff is introduced here.

## Decision (human)
- DELIVERED is terminal except for returns. The issue 6 test was replaced by a stricter one stating exactly DELIVERED -> RETURNED. Reason: the business rule changed on purpose.
